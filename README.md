# BOOKMATE

### 같은 책. 다른 생각.

책을 읽고 떠오른 생각을 다른 독자와 나누고, 나만의 독후감으로 이어가는 북클럽 웹 서비스입니다.

**진행 상태 · 배포 준비 중**

---

## 프로젝트를 만든 이유

책을 다 읽고도 막상 감상을 글로 쓰려면 어디서부터 시작해야 할지 막막할 때가 있습니다. 읽는 동안 떠올랐던 생각도 시간이 지나면 쉽게 잊히곤 합니다.

BOOKMATE는 **책에 대한 질문에 하나씩 답하다 보면, 그 기록이 한 편의 독후감으로 이어질 수 있지 않을까?**라는 생각에서 시작했습니다.

같은 책을 읽은 사람들의 다양한 시선을 살펴보고, 내 생각을 남기고, 그 기록을 바탕으로 글을 완성하는 경험을 제공합니다.

---

## 주요 경험

### 01. 같은 책을 읽은 사람들과 만나는 공간

열린 북클럽을 둘러보거나 책을 검색해 관심 있는 책의 북클럽에 참여할 수 있습니다. 책마다 마련된 질문을 통해 다른 독자들이 어떤 부분에 주목했는지 살펴봅니다.

### 02. 질문에서 시작하는 나의 생각

막연하게 감상을 작성하는 대신, 책에 대한 질문을 골라 답변을 남깁니다. 다른 독자의 답변을 읽으며 관점을 넓히고, 내가 남긴 답변은 이후에도 수정할 수 있습니다.

### 03. 내 기록을 한 편의 독후감으로

책을 선택하고, 독후감에 담고 싶은 내 답변을 골라 가져옵니다. 가져온 내용을 보완하거나 새로운 생각을 자유롭게 작성한 뒤, AI의 도움으로 독후감 초안을 만듭니다.

생성된 초안은 직접 수정하고 복사할 수 있어, 마지막까지 자신의 표현으로 글을 다듬을 수 있습니다.

## 구현에서 고민한 점

### 선택에 따라 자연스럽게 이어지는 작성 화면

책과 생각, 입력창을 처음부터 모두 보여주면 복잡해질 수 있다고 판단했습니다. 책을 선택하면 내 생각 목록이 나타나고, 생각을 선택하면 편집 영역이 펼쳐지도록 구성했습니다.

사용자가 별도의 ‘다음’ 버튼을 반복해서 누르지 않고도 작성 흐름을 따라갈 수 있도록 했습니다.

### 공개한 답변과 개인적인 글쓰기의 분리

독후감을 위해 문장을 고치는 과정이 북클럽에 남긴 공개 답변까지 바꾸지 않도록, 선택한 답변을 작성용 복사본으로 가져오게 했습니다.

공개된 생각은 유지하면서 독후감에서는 자유롭게 표현을 다듬을 수 있습니다.

### 서로 다른 책의 기록이 섞이지 않도록

독후감 작성에 사용할 답변을 선택한 책과 로그인 사용자 기준으로 조회하도록 구성했습니다. 작성 중 책을 변경할 때는 안내를 제공하고, 이전 책의 작성 상태가 새 독후감에 섞이지 않도록 처리했습니다.

### 메인과 작성 화면의 디자인 통일

화이트 배경과 그린·오렌지 포인트를 공통으로 사용하고, 글과 질문에 집중할 수 있도록 화면을 구성했습니다. 모바일에서는 카드와 입력 영역이 세로로 이어지도록 배치했습니다.
