# BOOKMATE

> **같은 책. 다른 생각.**
> 책을 중심으로 질문과 생각을 나누고, 자신의 기록을 바탕으로 AI 독후감 초안을 작성하는 북클럽 웹 서비스입니다.

사용자는 책을 검색해 북클럽에 참여하고, 질문에 답변을 남기며 다른 독자의 생각을 살펴볼 수 있습니다. 기록한 답변을 가져오거나 자유롭게 생각을 작성해 AI 독후감 초안을 만들고, 직접 수정할 수 있습니다.

**배포 주소:** https://bookmate-kmzj.onrender.com

## 프로젝트 개요

* **개발 형태:** 개인 프로젝트
* **개발 목적:** 독서 토론과 개인 기록, 독후감 작성을 연결하는 웹 서비스 구현
* **주요 특징:** 책별 북클럽, 공개 질문·답변, AI 독후감 작성, 반응형 UI
* **배포 예정:** Render · Neon PostgreSQL

## 주요 기능

| 기능     | 내용                                         |
| ------ | ------------------------------------------ |
| 회원 관리  | 회원가입, 로그인·로그아웃, 로그인 상태 유지                  |

| 답변 관리  | 공개 답변 작성, 본인 답변 수정                         |

| 반응형 화면 | PC·모바일에 맞춘 레이아웃                            |

## 주요 구현 내용

### 사용자 권한과 도서 식별

인증된 사용자 ID를 기준으로 답변 소유권을 확인하고, Backend에서 본인 답변만 수정할 수 있도록 처리했습니다. 도서는 ISBN을 우선 사용하고, ISBN이 없는 경우 제목과 작가 정보를 활용해 식별합니다.

### 단계별 독후감 작성

책을 선택하면 내 답변 목록이, 답변을 선택하면 편집 영역이 나타나도록 구성했습니다. 기존 기록이 없어도 자유롭게 생각을 작성하여 AI 독후감 초안을 생성할 수 있습니다.

### 공개 답변 보호와 상태 관리

가져온 답변은 작성용 복사본으로 사용하여 독후감 편집이 공개 답변 원본에 영향을 주지 않도록 했습니다. 책 변경 시 작성 내용을 확인하고, 계정 변경 시 이전 사용자의 데이터를 초기화하도록 구성했습니다.

## 주요 프로젝트 구조

| 경로                | 역할                         |
| ----------------- | -------------------------- |
| `app/routers/`    | API 요청 처리                  |
| `app/services/`   | 도서·답변 관리 및 AI 생성 로직        |
| `app/models.py`   | 요청·응답 모델                   |
| `app/database.py` | DB 접근 처리                   |
| `static/`         | 화면 구성, 스타일, API 호출 및 상태 관리 |

## 프로젝트를 통해 배운 점

* Frontend, Backend, DB, 외부 API가 연결되는 웹 서비스의 전체 흐름
* 로그인 확인과 데이터 수정 권한 검사의 차이
* 사용자 입력을 보존하고 책·계정별 데이터를 분리하는 상태 관리
* AI 코딩 도구의 결과를 검토하고 작은 단위로 개선하는 개발 과정
